## 役割

Tier2/3 判定者向けの構造化ルーブリック。共同研究者レビュー指摘(3)で追加。

### 位置づけ

Tier1 の check M が決定的に保証するのは**引用の実在（DOI/PMID）とメタデータ一致
（title/authors/year）**までである。「引用文献が本文の主張を実際に支持しているか」は
含意判断（entailment）であり、**決定的アサーションにはできない**。したがって本判定は
Tier2 に置き、クリティカル扱いで cross-model 盲検の対象に含める。

> **Tier1 CRITICAL にしてはならない理由（Codex Sol）**: 支持根拠が補足表や図注にのみ
> ある正しい引用が FAIL する一方、全文に同じ疾患名と "association" があるだけの
> 誤引用（対象集団・曝露方向・時点が逆）が PASS する。機械的な一致度では方向を
> 判定できない。

### 3値 verdict（2値にしてはならない）

各引用×主張ペアについて、次の3値で返す。**FAIL に相当するのは `CONTRADICTED` のみ**。

| verdict | 意味 | 扱い |
|---|---|---|
| `SUPPORTED` | 引用元が当該主張を支持している | PASS |
| `NOT_ASSESSABLE` | 取得できた本文（多くは abstract）からは判断できない | **FAIL ではない**。coverage に記録 |
| `CONTRADICTED` | 引用元が当該主張と矛盾する、または主張と別のことを述べている | FAIL 相当 → Tier3 外部議論へ |

**`NOT_ASSESSABLE` を不支持と扱わないこと**が本ルーブリックの要である。Methods の詳細や
副次結果を引く正当な引用は abstract に現れない。2値化すると偽陽性が暴走し、
DESIGN §7 の precision ≥ 80% と両立しない。

### 取得レベルと INCOMPLETE の扱い

- **既定は abstract ベース**（PubMed E-utilities で概ね取得可能。Crossref は abstract
  欠落が多い）。全文 PDF 前提の設計にすると有料誌が混ざるだけで INCOMPLETE の洪水になる。
- 取得不能な参照は per-ref INCOMPLETE として coverage proof に記録するが、
  **それ単独で run をハードブロックしない**。
- ただし `NOT_ASSESSABLE` ＋ 取得不能が全参照の **30% 超**になったら、G2 の人間に
  サマリーを surface し、人間が数本を抜き取り検査する。

## 判定観点

引用ごとに次を順に確認する。

1. **主張の特定**: その引用が支えている原稿の文を1文で抜き出す。複数の主張を1つの引用が
   支えている場合は分割して判定する。
2. **方向の一致**: 曝露→アウトカムの向き、効果の符号が一致しているか。
   （最頻の誤引用パターンはここ。「関連あり」だけの一致で PASS にしない）
3. **対象集団の一致**: 年齢層・疾患・国/文脈が主張の一般化範囲と両立するか。
4. **時点・デザインの一致**: 横断研究を縦断的主張の根拠にしていないか。
5. **強度の一致**: 原稿が「確立している」と書いているのに、引用元が探索的・限定的な
   結果しか示していないか（誇張引用）。

## 判定基準

各引用×主張ペアを **SUPPORTED / NOT_ASSESSABLE / CONTRADICTED** で評価する。
判定観点1〜5のいずれかが明確に破れていれば `CONTRADICTED`、取得本文から判断できなければ
`NOT_ASSESSABLE`（**FAIL ではない**）、全観点が整合していれば `SUPPORTED`。
観点2（方向の一致）の破れは最頻の誤引用パターンであり、「関連あり」だけの一致で
`SUPPORTED` にしてはならない。

## 出力

各引用について: `{reference_id, claim_sentence, verdict, evidence_span, reason}`。
`evidence_span` は判定根拠となった引用元テキストの抜粋（judgment を検証可能にする）。
根拠スパンの無い verdict は**無効票**として扱う（DESIGN §5.3 の「根拠なき PASS は無効票」
と同じ規律）。

### CONTRADICTED の後段

`CONTRADICTED` は即 FAIL 確定にせず、クリティカル M の既存経路（Tier3 外部議論）へ回す。
abstract は結論を単純化して書かれるため、「abstract とは矛盾に見えるが本文では整合」が
実在する。
